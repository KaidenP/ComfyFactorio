# FluidPrototype

> **Parent:** [[Prototype]] · **Type name:** `fluid`

A fluid.

## Properties

### icons
- **Type:** array<[[IconData]]>
- **Optional**
Can't be an empty array.

### icon
- **Type:** [[FileName]]
- **Optional**
Path to the icon file.

Only loaded, and mandatory if `icons` is not defined.

### icon_size
- **Type:** [[SpriteSizeType]]
- **Optional**
- **Default:** `64`
The size of the square icon, in pixels. E.g. `32` for a 32px by 32px icon. Must be larger than `0`.

Only loaded if `icons` is not defined.

### default_temperature
- **Type:** [[float (type)]]
Also the minimum temperature of the fluid. Has to be lower than `max_temperature`.

### base_color
- **Type:** [[Color (type)]]
Used by bars that show the fluid color, like the flamethrower turret fill bar in the tooltip, or the fill bar for the fluid wagon tooltip; and for the pipe windows and storage tank fill gauges.

### flow_color
- **Type:** [[Color (type)]]
Used only for pipe windows or storage tank fill gauges.

### visualization_color
- **Type:** [[Color (type)]]
- **Optional**
Color to use for visualization. This color should be vibrant and easily distinguished.

If not specified, this will be auto-generated from `base_color` by converting to HSV, decreasing saturation by 10% and setting value to 80%.

### max_temperature
- **Type:** [[float (type)]]
- **Optional**
- **Default:** value of `default_temperature`

### heat_capacity
- **Type:** [[Energy]]
- **Optional**
- **Default:** `"1kJ"`
Joule needed to heat 1 Unit by 1 °C.
**Examples:**

```
heat_capacity = "0.2kJ"
```

### fuel_value
- **Type:** [[Energy]]
- **Optional**
- **Default:** `"0J"`
**Examples:**

```
fuel_value = "3MJ"
```

### emissions_multiplier
- **Type:** [[double (type)]]
- **Optional**
- **Default:** `1.0`
Scales pollution generated when the fluid is consumed.

### gas_temperature
- **Type:** [[float (type)]]
- **Optional**
- **Default:** max value of float
Above this temperature the `gas_flow` animation is used to display the fluid inside storage tanks and pipes.

### draw_as_glow
- **Type:** [[boolean (type)]]
- **Optional**
- **Default:** `false`
Whether the fluid should glow in pipe and storage tank windows. The glow is only drawn when the [[FeatureFlags#expansion_shaders|expansion_shaders]] feature flag is enabled.

### auto_barrel
- **Type:** [[boolean (type)]]
- **Optional**
- **Default:** `true`
Whether the fluid should be included in the barrel recipes automatically generated by the base mod.

This property is not read by the game engine itself, but the base mod's data-updates.lua file. This means it is discarded by the game engine after loading finishes.

### hidden
- **Type:** [[boolean (type)]]
- **Optional**
- **Default:** `false`
- **Overrides parent**
Hides the fluid from the signal selection screen.

### spent_fluid
- **Type:** [[SpentFluidSpecification (type)]]
- **Optional**
Fluid and amount produced per 1 unit of fluid consumed. Used by Generator only if [[GeneratorPrototype#spent_fluid|GeneratorPrototype::spent_fluid]] is not set and it has [[GeneratorPrototype#output_fluid_box|GeneratorPrototype::output_fluid_box]]. Used by FluidEnergySource only if [[FluidEnergySource#spent_fluid|FluidEnergySource::spent_fluid]] is not set and it has [[FluidEnergySource#output_fluid_box|FluidEnergySource::output_fluid_box]].

## Example

```
{
  type = "fluid",
  name = "water",
  default_temperature = 15,
  max_temperature = 100,
  heat_capacity = "0.2kJ",
  base_color = { r = 0, g = 0.34, b = 0.6 },
  flow_color = { r = 0.7, g = 0.7, b = 0.7 },
  icon = "__base__/graphics/icons/fluid/water.png",
  icon_size = 64,
  order = "a[fluid]-a[water]"
}
```
