# GuiStyle

> **Parent:** [[PrototypeBase]] · **Type name:** `gui-style` · **Instance limit:** 1

The available GUI styles.

## Properties

### default_tileset
- **Type:** [[FileName]]
- **Optional**
- **Default:** `""`

### default_sprite_scale
- **Type:** [[double (type)]]
- **Optional**
- **Default:** `1`

### default_sprite_priority
- **Type:** [[SpritePriority]]
- **Optional**
- **Default:** `"medium"`
