# Prototype

> **Parent:** [[PrototypeBase]] · **Abstract**

## Properties

### factoriopedia_alternative
- **Type:** [[string (type)]]
- **Optional**
The ID type corresponding to the prototype that inherits from this.

For example, if this is an [[EntityPrototype]], this property's type is [[EntityID (type)|EntityID]].

### custom_tooltip_fields
- **Type:** array<[[CustomTooltipField (type)]]>
- **Optional**
Allows to add extra description items to the tooltip and Factoriopedia.
