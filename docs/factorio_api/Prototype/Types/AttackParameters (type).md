# AttackParameters

*Note: `AttackParameters (type)`.*

Loaded as one of the [[BaseAttackParameters]] extensions, based on the value of the `type` key.

## Type

[[ProjectileAttackParameters]] — Loaded when the `type` is `"projectile"`. | [[BeamAttackParameters]] — Loaded when the `type` is `"beam"`. | [[StreamAttackParameters]] — Loaded when the `type` is `"stream"`.
