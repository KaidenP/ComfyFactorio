# IngredientPrototype

Item or fluid ingredient.

## Type

[[ItemIngredientPrototype]] — Loaded when the `type` is `"item"`. | [[FluidIngredientPrototype]] — Loaded when the `type` is `"fluid"`.

## Examples

```
{type="item", name="steel-plate", amount=8} -- item ingredient
```

```
{type="fluid", name="water", amount=50} -- fluid ingredient
```
