# ProductionType

*Note: `ProductionType (type)`.*

> **Inline**

Specifies how the entity will utilize this fluidbox. `input-output` should only be used for boilers in fluid heating mode.

## Type

`"none"` | `"input"` | `"input-output"` | `"output"`
