# ResearchIngredient

*Note: `ResearchIngredient (type)`.*

Defines the amount of an item required to research one unit of a [[TechnologyPrototype|technology]]. The first member of the tuple is the name of a [[ItemPrototype]] and the second is the amount. Amount must not be 0.

## Type

([[ItemID (type)]], [[uint16 (type)]])

## Examples

```
{"automation-science-pack", 1}
```
