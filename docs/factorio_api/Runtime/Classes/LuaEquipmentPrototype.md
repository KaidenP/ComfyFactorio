# LuaEquipmentPrototype

> **Extends:** [[LuaPrototypeBase]]

Prototype of a modular equipment.

## Attributes

### shape
- **Type:** table
Shape of this equipment prototype.

### take_result
- **Type:** [[LuaItemPrototype]]
- **Optional**
The result item when taking this equipment out of an equipment grid, if any.

### energy_production
- **Type:** [[double]]
The max power generated by this equipment.

### energy_per_shield
- **Type:** [[double]]
The energy per shield point restored. 0 for non-shield equipment.

### logistic_parameters
- **Type:** table
- **Optional**
The logistic parameters for this roboport equipment.

### energy_source
- **Type:** [[LuaElectricEnergySourcePrototype]]
The energy source prototype for the equipment.

### equipment_categories
- **Type:** array<[[string]]>
Category names for this equipment. These [[LuaEquipmentGridPrototype#equipment_categories|categories]] will be used to determine whether this equipment is allowed in a particular equipment grid.

### burner_prototype
- **Type:** [[LuaBurnerPrototype]]
- **Optional**
The burner energy source prototype this equipment uses, if any.

### electric_energy_source_prototype
- **Type:** [[LuaElectricEnergySourcePrototype]]
- **Optional**
The electric energy source prototype this equipment uses, if any.

### background_color
- **Type:** [[Color]]
The background color of this equipment prototype.

### attack_parameters
- **Type:** [[AttackParameters]]
- **Optional**
The equipment attack parameters.

### automatic
- **Type:** [[boolean]]
Whether this active defense equipment is automatic. Returns false if not active defense equipment.

### solar_panel_performance_at_day
- **Type:** [[double]]
- **Optional**

### solar_panel_performance_at_night
- **Type:** [[double]]
- **Optional**

### solar_panel_solar_coefficient_property

- **Optional**

### gui_mode
- **Type:** `"all"` | `"none"` | `"admins"`
- **Optional**

### darkness_to_turn_on
- **Type:** [[float]]
- **Optional**

### sunglasses
- **Type:** [[boolean]]
- **Optional**

### valid
- **Type:** [[boolean]]
Is this object valid? This Lua object holds a reference to an object within the game engine. It is possible that the game-engine object is removed whilst a mod still holds the corresponding Lua object. If that happens, the object becomes invalid, i.e. this attribute will be `false`. Mods are advised to check for object validity if any change to the game state might have occurred between the creation of the Lua object and its access.

### object_name
- **Type:** [[string]]
The class name of this object. Available even when `valid` is false. For LuaStruct objects it may also be suffixed with a dotted path to a member of the struct.
