# DifficultySettings

Technology difficulty settings. Updating any of the attributes will immediately take effect in the game engine.

## Fields

### technology_price_multiplier
- **Type:** [[double]]
- **Writable:** [[double]]
A value in range [0.001, 100000].

### spoil_time_modifier
- **Type:** [[double]]
- **Writable:** [[double]]
A value in range [0.01, 100].
