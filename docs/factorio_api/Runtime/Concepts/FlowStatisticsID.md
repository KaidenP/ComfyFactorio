# FlowStatisticsID

Identifies a statistics prototype, depending on the statistics type.

## Type

[[ItemWithQualityID]] — Used with item production statistics. | [[FluidID]] — Used with fluid production statistics. | [[EntityWithQualityID]] — Used with electric network, entity build count, and kill count statistics. | [[EntityID]] — Used with pollution statistics.
