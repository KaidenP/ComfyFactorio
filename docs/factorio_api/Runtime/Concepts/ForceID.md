# ForceID

A force may be specified in one of three ways.

## Type

[[string]] — Name of the force, same as [LuaForce::name](runtime:LuaForce::name). | [[uint8]] — Index of the force, same as [LuaForce::index](runtime:LuaForce::index). | [[LuaForce]] — A reference to [LuaForce](runtime:LuaForce) may be passed directly.
