# PathfinderWaypoint

## Fields

### position
- **Type:** [[MapPosition]]
The position of the waypoint on its surface.

### needs_destroy_to_reach
- **Type:** [[boolean]]
`true` if the path from the previous waypoint to this one goes through an entity that must be destroyed.
