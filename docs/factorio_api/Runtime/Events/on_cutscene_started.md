# on_cutscene_started

Called when a cutscene starts.

## Data

### player_index
- **Type:** [[uint32]]
The player the cutscene is being shown to.

### name
- **Type:** [[defines.events]]
Identifier of the event.

### tick
- **Type:** [[MapTick]]
Tick the event was generated.
