# on_player_display_scale_changed

Called when the display scale changes for a given player.

## Data

### player_index
- **Type:** [[uint32]]
The player

### old_scale
- **Type:** [[double]]
The old display scale

### name
- **Type:** [[defines.events]]
Identifier of the event.

### tick
- **Type:** [[MapTick]]
Tick the event was generated.
