Called when a research finishes.

### research
- **Type:** [[LuaTechnology]]
The researched technology

### by_script
- **Type:** [[boolean]]
If the technology was researched by script.

### name
- **Type:** [[defines.events]]
Identifier of the event.

### tick
- **Type:** [[MapTick]]
Tick the event was generated.
