# on_research_reversed

Called when a research is reversed (unresearched).

## Data

### research
- **Type:** [[LuaTechnology]]
The technology un-researched

### by_script
- **Type:** [[boolean]]
If the technology was un-researched by script.

### name
- **Type:** [[defines.events]]
Identifier of the event.

### tick
- **Type:** [[MapTick]]
Tick the event was generated.
