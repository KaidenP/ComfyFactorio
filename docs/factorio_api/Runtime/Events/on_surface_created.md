# on_surface_created

Called when a surface is created.

This is not called when the default surface is created as it will always exist.

## Data

### surface_index
- **Type:** [[uint32]]

### name
- **Type:** [[defines.events]]
Identifier of the event.

### tick
- **Type:** [[MapTick]]
Tick the event was generated.
